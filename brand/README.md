# Surehand MCP logo

The mark is an S drawn as a Pen tool path: one smooth anchor in the middle, with its two handles on the same 45° line as the straight middle stroke.

| File | Use |
|---|---|
| `surehand-mark.svg` | the mark on light backgrounds (ink, dark green handles) |
| `surehand-mark-reversed.svg` | the mark on dark backgrounds (ivory, green handles) |
| `surehand-mark-mono.svg` | one colour (print, stamps) |
| `surehand-icon.svg` | app icon, 128 px and up |
| `surehand-icon-small.svg` | app icon, 32–64 px (no centre anchor) |
| `surehand-icon-16.svg` | app icon, 16 px (the S only) |
| `surehand-tile.svg` | the S on the green tile, as the After Effects panel draws it (`#tile` in extension/index.html); used by the installers (installer/app.json `tile`) |
| `png/icon-<size>.png` | app icon PNGs, 16–1024 px |
| `png/mark-*.png` | the mark as PNG (128 and 512 px) |
| `png/lockup-light.png`, `png/lockup-dark.png` | mark + "Surehand MCP for Adobe® After Effects®" (README header) |
| `Surehand.icns` | macOS icon |
| `Surehand.ico` | Windows icon (16–256 px; used by the Windows installer) |

Colours: ink `#14161A`, ivory `#F2EFE8`, green `#3DD68C` (on dark), dark green `#14874F` (on light).
Wordmark: Space Grotesk 600 ("Surehand") and 500 ("MCP").

`server/assets/icon.png` (the Claude Desktop extension icon) is `png/icon-512.png`. The panel in After Effects draws the mark inline (extension/index.html). The Mac installer's background images are in `installer/mac/pkg/resources/`.

The name "After Effects" is never part of the logo itself: Adobe and After Effects are trademarks of Adobe.
