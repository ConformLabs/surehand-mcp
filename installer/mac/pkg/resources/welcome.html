Surehand MCP @VERSION@

Surehand MCP lets AI apps (Claude, ChatGPT, Codex, Cursor) control Adobe After Effects on this Mac. Everything runs locally.

This installer puts everything in your own home folder. It does not need an administrator password and does not change anything for other users of this Mac.

What gets installed

  • A private copy of Node.js in ~/.aemcp/node (used only by Surehand MCP)
  • The Surehand MCP server in ~/.aemcp/server, and its settings in ~/.aemcp/config.json
  • The After Effects panel in ~/Library/Application Support/Adobe/CEP/extensions
  • A connection entry in each AI app found on this Mac: Claude Desktop, Claude Code, ChatGPT desktop / Codex and Cursor. Other settings in those apps are left as they are; a settings file edited directly is backed up first (*.aemcp.bak).

Source code, documentation and help: github.com/ConformLabs/surehand-mcp
